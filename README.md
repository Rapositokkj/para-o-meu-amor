# 💗 Para Minha Amada

Um pequeno site feito com muito carinho para uma pessoa muito especial. ❤️

A ideia é simples: uma pequena pergunta, uma escolha... e uma surpresa no final. 👀💕

## ✨ Sobre o projeto

Esse site foi criado como uma pequena demonstração de carinho e, principalmente, para arrancar um sorriso de quem eu amo.

Tudo foi feito do zero utilizando:

* 🌐 HTML
* 🎨 CSS
* ⚡ JavaScript

## 💌 Como funciona

Ao entrar no site, você encontrará uma pergunta muito importante...

Escolha com cuidado. 😏

Depois da resposta, uma pequena surpresa espera por você. ❤️

## 📱 Responsivo

O site foi desenvolvido para funcionar também em dispositivos móveis, permitindo que a surpresa seja acessada pelo celular.

## ❤️ Feito com amor

Esse projeto foi feito especialmente para uma pessoa que significa muito para mim.
